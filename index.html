Impostazioni

Deve corrispondere esattamente al token scritto in cima a Code.gs. Senza, il server rifiuta ogni richiesta anche conoscendo l'indirizzo Web App.

Con questo URL configurato, i dati si aggiornano automaticamente su ogni dispositivo dove installi l'app.

Quando passa l'orario di un ricontatto o di un appuntamento, l'app ti chiede l'esito.

Appuntamenti rossi, ricontatti blu, ricontatti aggiuntivi viola. Cambia solo il colore degli eventi.
